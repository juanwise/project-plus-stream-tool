Best of

Put the player coming from winners as Player 1. If the losers-side player wins the first set, press Bracket reset: scores go to 0-0 and the overlays show "Grand Finals Reset".

Import from Start.gg

Fills names, tags, countries and characters. Get a free token in start.gg → your profile → Developer Settings → Create new token. Review the result, then press Update.

Bracket from Start.gg

Show

Paste the event link and press Update bracket. The overlay changes only when you press the button, so press it again after each set. Uses the API token from the Top 8 tab.

Overlays for OBS

In OBS add a Browser source for each one, size 1920 x 1080 (other sizes also work: the overlay scales to fit), and tick "Shutdown source when not visible" and "Refresh browser when scene becomes active" so the animations play every time you show the overlay.

Logo

Your logo appears on every overlay exactly as it is (no theme colours): centred on the VS screen and the scoreboard, on both sides of the title of Top 8 and Bracket, and on the waiting screen. PNG with a transparent background works best.

Bigger or custom art

The art that comes with the tool is 384 x 480. To use your own, put images in this folder (they win over the bundled ones):

stream-tool-data/custom-art/<fighter>/<costume number>.png

For example custom-art/mario/1.png. Fighter names are the lowercase names with underscores (king_dedede, mr_game_and_watch, rob). PNG, WebP or JPG; transparent background; any size. Same for icons in custom-icons. Press F5 on the overlay (or refresh the OBS source) to load new images.
